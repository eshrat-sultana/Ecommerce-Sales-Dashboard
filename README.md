# E-commerce Sales Dashboard (Interactive Dashboard using Microsoft Power BI)

## Project Objective

The objective of this project is to analyze e-commerce and retail sales data and provide meaningful business insights into sales performance, profitability, product categories, regional performance, and shipping methods.

The dashboard enables business and sales teams to monitor key performance indicators, compare current performance with the previous year, and identify products and categories contributing to overall business performance.

## Dataset Used

* E-commerce/Retail Sales Dataset (CSV/Excel)

## Questions (KPIs)

* What are the total YTD sales, profit, and quantity?
* How does current YTD sales performance compare with the previous year?
* How does profit compare with the previous year?
* What is the current profit margin?
* Which product categories generate the highest sales?
* Which products are the top and bottom performers?
* Which regions contribute the most to sales?
* Which shipping mode contributes the highest sales?
* How does sales performance vary across different states?
* How does sales performance change by customer segment?

## Process

* Collected and reviewed the raw sales dataset.
* Cleaned and transformed the data using Power Query.
* Created a Calendar/Date table for time-based analysis.
* Built a structured data model connecting sales, date, product, customer, and geographic information.
* Developed DAX measures for YTD, PYTD, YoY %, and Profit Margin.
* Created KPI cards with YoY indicators and trend analysis.
* Designed interactive charts, tables, maps, and slicers.
* Added cross-filtering to enable interactive analysis across the dashboard.
* Applied conditional formatting and a custom dashboard theme.

* **Standard Class** contributes approximately **60%** of sales by shipping mode.
* **West (32%)** and **East (28%)** are the highest-contributing regions by sales.
* The dashboard highlights the top 5 and bottom 5 products based on YTD sales.
